# TaskMate — Student Productivity Manager 📚

A simple and responsive web application that helps students organize assignments, manage deadlines, and track their academic tasks in one place.

## 🌐 Live Demo

**[Open TaskMate](https://zkhan2006.github.io/TaskMate_01/)**

## ✨ Features

- **Dashboard:** View total, pending, completed, and overdue tasks.
- **Add Tasks:** Create assignments with a title, subject, deadline, and priority.
- **Edit Tasks:** Update assignment details whenever needed.
- **Delete Tasks:** Remove tasks that are no longer required.
- **Task Completion:** Mark assignments as completed or pending.
- **Search:** Find tasks by assignment title or subject.
- **Filters:** Filter assignments by subject, priority, and status.
- **Deadline Tracking:** Identify overdue assignments.
- **Local Storage:** Keep tasks saved in the browser after refreshing the page.
- **Responsive Design:** Use the application on desktop and mobile screens.

## 🛠️ Technologies Used

- **HTML5** — Structure of the application
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Task management, filtering, validation, and interactivity
- **Browser LocalStorage** — Local data persistence
- **Git & GitHub** — Version control and source code hosting
- **GitHub Pages** — Website deployment

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/zkhan2006/TaskMate_01.git
   ```

2. Open the project folder:

   ```bash
   cd TaskMate_01
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No additional packages or installations are required to run the frontend.

## 💾 Data Storage

TaskMate uses browser LocalStorage to save tasks on the current browser and device. Tasks generally remain available after refreshing the page.

**Note:** This version does not include a backend database or user authentication. Data is not automatically synchronized across different devices or browsers.

## 🎯 Project Objective

The objective of TaskMate is to help students manage their academic responsibilities efficiently by organizing assignments, setting deadlines, prioritizing work, and monitoring task completion.

This project also demonstrates practical web development concepts, including DOM manipulation, event handling, form validation, responsive layouts, and browser-based data storage.
